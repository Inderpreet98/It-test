Operating System Installation Guide

An interactive resource lesson plan for IT students

1. The Universal 5-Step Process

Regardless of which operating system you are deploying, almost all installations follow this exact underlying workflow sequence:

Step 1: PrepCreate a bootable USB medium from an ISO image.
Step 2: BootInterrupt startup (F2/F12) to boot from the USB.
Step 3: PartitionFormat, wipe, or slice the destination drive.
Step 4: CopyAutomated extraction of core system files.
Step 5: SetupConfigure user profiles, locales, and privacy networks.

2. OS-Specific Installation Steps

Click the buttons below to switch between operating systems and view their specific manual steps:

Windows Installation Architecture

  1. Boot from Flash Drive: Power on the device while tapping your manufacturer's boot menu hotkey (typically F12 or F2) and choose the UEFI USB option.
  2. Locale Selection: Choose language, time formats, and keyboard configuration inputs, then select Install Now.
  3. License Activation: Enter your 25-character product token key, or choose "I don't have a product key" for evaluation mode testing.
  4. Custom Selection: Choose Custom: Install Windows only (advanced) to manage structural drive layouts.
  5. Drive Partitioning: Select your target drive partition, clear out old logical paths, or choose unallocated raw storage blocks.
  6. Reboot Cycle: Once standard file copying wraps up, pull the USB thumb-drive out immediately during the reboot count down so it does not loop the installer.
  7. OOBE Configuration: Complete out-of-box customizations (Microsoft profile mapping, PIN assignment, telemetry parameters).

Ubuntu Linux Installation Architecture

  1. Enter Live Environment: Boot the installation USB media and select **Try or Install Ubuntu** from the GRUB loader interface.
  2. Trigger Setup Wizard: Click the main desktop icon shortcut to load the direct graphical desktop distribution manager wizard.
  3. Network Handshake: Bind onto local Wi-Fi or Ethernet options to permit automatic system patch acquisition arrays.
  4. Package Scale Profiles: Choose a *Normal Installation* for office application software bundles, or a *Minimal Installation* for clean environment testbeds.
  5. Drive Layout Allocations: Opt to *Erase disk and install Ubuntu* for baseline operations, or select *Something Else* to configure custom root (/), /home, or swap memory spaces.
  6. Map Target Boundaries: Select regional coordinate frames on the layout map graphic to set system timezone references.
  7. Credential Generation: Input user handles, domain naming conventions, and local administrative system security passwords.

macOS Recovery Installation Architecture

  1. Activate Base Recovery Mode: Boot hardware using operational key profiles (Hold down Cmd + R on Intel frameworks, or hold down the physical power button on Apple Silicon builds).
  2. Format Target Volumes: Launch the native **Disk Utility** asset from the screen window interface menu.
  3. Clean Outbound Paths: Select your main hardware drive volume, click **Erase**, and format the clean target workspace as **APFS**. Close the tool window layout when finished.
  4. Trigger Base Setup: Select **Reinstall macOS** from the core utility menu system framework interface.
  5. Accept Agreements: Review operating terms profiles and bind structural software paths onto your freshly cleared APFS volume node.
  6. File Streaming: Allow the unit to process cloud repository streaming installations (Ensure physical power lines remain connected).
  7. Personalization Wizard: Complete native system configurations (Apple ID binding, FileVault storage security, Accessibility mappings).
